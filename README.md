# SUB-UI

SUB-UI 帮你把多个订阅或单个节点整理到一起，生成一个链接供客户端使用。

## 使用流程

```text
添加订阅或节点 → 创建 SUB → 选择 SUB 生成 URL → 添加到客户端
```

| 名称 | 简单理解 |
|---|---|
| SUB | 保存订阅来源或单个节点，可重复使用 |
| URL | 选择要包含的 SUB，生成对外订阅链接 |

一个 SUB 可以给多个 URL 使用，一个 URL 也可以组合多个 SUB。

## 部署

只需创建一个 Cloudflare KV Namespace，并绑定为 **`KV`**。无需设置环境变量。

| Pages（连接 GitHub） | Workers（粘贴代码） |
|---|---|
| 1. Fork 项目仓库并在 Cloudflare Pages 连接它。<br>2. 构建命令留空，输出目录填写 `.`。<br>3. 在 **Settings → Functions → KV Namespace Bindings** 绑定 KV，变量名填写 `KV`，然后部署。 | 1. 创建 Worker，将项目 `_worker.js` 的完整内容粘贴并部署。<br>2. 在 **Settings → Bindings → KV Namespace** 绑定 KV，变量名填写 `KV`。<br>3. 保存并部署。 |

## 进入管理员后台

部署完成后打开：

```text
https://你的域名/admin
```

首次进入时没有预设管理员账号密码。请在后台的 **安全** 设置中创建账号和密码；之后登录后台进行管理。也可以在 **站点** 设置中修改管理员路径，修改后使用新路径进入。

### 后台可以编辑什么

| 页面 / 设置 | 可以编辑 |
|---|---|
| SUB | 订阅来源、单个节点、备注及排序 |
| URL | 订阅路径、名称、绑定的 SUB、排除关键词、推荐更新时间；可管理或销毁链接 |
| SUBAPI / SUBCONFIG | 转换地址、备注、默认配置及排序 |
| 站点 | 站点名称、Logo、管理员路径 |
| 安全 | 管理员账号和密码 |
| JSON 管理 | 搜索、查看、导入和删除配置数据 |

### 新手怎么开始

| 步骤 | 要做什么 |
|---|---|
| 1. 添加来源 | 在 SUB 中添加机场订阅地址或单个节点 |
| 2. 整理节点 | 按地区、用途等创建 SUB，并添加对应来源 |
| 3. 生成链接 | 在主页选择要使用的 SUB，设置链接路径后生成 URL |
| 4. 添加客户端 | 复制自适应链接，或按客户端选择专用格式 |
| 5. 管理链接 | 回到主页查看本机生成记录，或打开链接管理页面维护 |

## 功能一览

| 功能 | 说明 |
|---|---|
| 订阅聚合 | 混合多个机场订阅和单个节点，生成统一订阅 |
| 节点去重 | 汇总来源时去除重复节点 |
| 格式转换 | 自动识别客户端，也可指定输出格式 |
| 节点过滤 | 按关键词排除节点名称中匹配的节点 |
| 自定义路径 | 为公开订阅设置易记路径，也可自动生成 |
| 更新提示 | 设置是否向客户端提供建议的更新间隔 |
| 链接保护 | 创建链接时可设置销毁密钥 |
| 状态检测 | 检查 SUBAPI、SUBCONFIG 以及生成链接状态 |
| 排序管理 | 调整 SUB、SUBAPI、SUBCONFIG 的显示顺序 |
| 数据管理 | 搜索、查看和删除 JSON 配置数据 |
| 网站设置 | 修改站点名称、Logo、首页显示和管理员入口 |
| 深色模式 | 管理后台和订阅页面适配系统深色外观 |

## 订阅链接格式

假设你的订阅链接是 `https://sub.example.com/japan`，不同客户端可使用：

| 客户端格式 | 订阅地址 |
|---|---|
| 自适应 | `https://sub.example.com/japan` |
| Base64 | `https://sub.example.com/japan?b64` |
| Clash | `https://sub.example.com/japan?clash` |
| Sing-box | `https://sub.example.com/japan?sb` |
| Surge | `https://sub.example.com/japan?surge` |
| Loon | `https://sub.example.com/japan?loon` |

把示例中的域名和路径换成自己的即可。通常直接使用自适应链接。

## 二维码怎么用

| 客户端 | 导入方式 |
|---|---|
| Sing-box | 扫描 Sing-box 专属二维码 |
| iPhone / iPad | 在 Safari 中长按 Sing-box 专属二维码，选择导入 Sing-box |
| 其他客户端 | 扫描对应格式的订阅二维码，或复制订阅链接添加 |

## 常见设置

| 设置 | 用途 | 小提示 |
|---|---|---|
| 排除节点 | 过滤广告、群组信息等节点 | 每行一个关键词，也可用逗号或空格分隔 |
| 推荐更新时间 | 告诉客户端建议多久更新一次 | 是否按建议更新由客户端决定 |
| 销毁密钥 | 防止他人销毁公开链接 | 创建链接时设置并自行保存 |
| 生成记录 | 在主页查看之前生成的链接 | 保存在当前浏览器，不会跨设备同步 |

## 管理页面

| 页面 | 可以做什么 |
|---|---|
| 主页 | 生成聚合订阅、查看本机生成记录、复制链接和二维码 |
| 公开订阅页 | 复制不同格式的订阅链接、显示二维码、编辑或销毁当前链接 |
| 管理后台 | 管理 SUB、URL、转换后端、转换规则和网站设置 |
| JSON 管理 | 搜索、查看或删除保存的配置 |

订阅链接是公开访问地址。请勿在链接名称或节点备注中填写密码等敏感信息。
